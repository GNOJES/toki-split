# toki-split — N등분 챌린지

제한시간 안에 손으로 도형을 균등하게 자르는 한국어 모바일 웹게임입니다. 기존 HTML 프로토타입의 10개 스테이지, 자유곡선 절단 및 정확도 평가 방식을 유지했습니다. 화면은 홈 → 스테이지 선택 → 모바일 전체 화면 플레이 순서로 구성합니다. 서버 API·DB·런타임 라이브러리는 사용하지 않습니다.

## 로컬 실행

Node.js 20 이상:

```sh
npm run dev
```

[http://127.0.0.1:5173](http://127.0.0.1:5173)을 엽니다. 게임 실행에는 `npm install`이 필요 없습니다. 포트 변경은 `PORT=8080 npm run dev`로 할 수 있습니다.

ES 모듈을 사용하므로 `index.html`을 `file://`로 직접 열지 말고 HTTP 정적 서버로 실행하세요. `index.html`과 `src/`를 그대로 정적 호스팅할 수 있으며 직접 정적 호스팅할 때 별도 빌드가 필요하지 않습니다. Vercel에서는 `npm run build`로 게임 파일만 `dist/`에 복사해 배포합니다.

## 플레이

- 홈의 **게임 시작**을 누르고 스테이지를 선택하면 별도 팝업 없이 바로 플레이합니다.
- 스테이지별 제한시간은 기존의 1/10인 **2~5.8초**입니다. 화면과 입력 준비가 끝난 뒤 시간을 재며, 재도전·다음 스테이지도 바로 시작합니다.
- 마우스나 손가락으로 도형을 가로질러 그립니다. 그린 궤적을 그대로 적용하며 직선으로 보정하거나 경계까지 연장하지 않습니다.
- 실제로 조각이 늘어나지 않거나 목표 개수를 초과한 절단은 저장하지 않습니다. 한 절단으로 여러 조각이 나뉠 수 있습니다.
- **되돌리기**는 진행 중 직전 절단을 복원합니다. **다시하기**는 선택한 스테이지를 즉시 새로 시작합니다.
- 게임 화면은 `100dvh`와 화면 안전영역에 맞춰 스크롤 없이 배치합니다. 보드는 가용 가로·세로에 맞는 정사각형이며 화면 크기가 바뀌면 진행 중인 입력을 취소합니다. 스테이지 목록은 별도 화면에만 표시하고, 선택 화면의 목록 스크롤은 허용합니다.
- 결과 하단 아이콘은 **재도전 / 스테이지 선택 / 다음 스테이지**입니다. 마지막 스테이지의 다음 아이콘은 전체 결과로 연결합니다. 큰 별 3개와 “별 3개 · 정확도 98% 이상” 안내를 표시합니다.
- **게임 방법**을 열거나 탭을 다른 곳으로 전환하면 플레이 시간을 일시정지하고 진행 중인 드래그를 취소합니다.
- 목표 조각 수가 되면 각 조각에 색상과 실제 면적 비율을 표시하고, 약 2.6초 후 정확도·별점·조각별 비율·목표 비율·남은 시간·최고 기록을 보여줍니다.
- 최고 기록은 기존 `toki-split-best-v1` localStorage 키를 유지합니다. 저장이 차단되어도 플레이할 수 있습니다.

## 절단과 면적 계산

기존 방식 그대로 560×560 래스터 마스크에 폭 3.2px의 절단 경로를 지우고 4방향 연결 요소를 찾습니다. 빠른 드래그는 이벤트 사이를 선분으로 연결하고, 지원 브라우저에서는 coalesced pointer samples도 보존합니다. 미리보기만 `requestAnimationFrame`으로 합쳐 이벤트마다 전체 화면을 반복해서 그리는 비용을 줄입니다.

기존의 극소 영역 기준 `max(12px, 원래 면적 × 0.00025)`를 유지합니다. 기준보다 작은 래스터 잡음은 흡수하고, 절단선 픽셀을 인접 영역에 배분해 원래 도형 픽셀은 정확히 한 조각에만 속하게 합니다. 최종 면적 합계는 원래 래스터 면적과 일치합니다. 영역 ID는 32비트로 관리하고, 모든 픽셀이 지워지는 극단적인 입력에도 원래 면적을 잃지 않도록 처리합니다.

정확도 공식은 다음과 같습니다.

```text
평균 면적 = 원래 면적 / 조각 수 N
절대 오차 = Σ |조각 면적 - 평균 면적|
정확도 = 100 × (1 - 절대 오차 / (2 × 원래 면적 × (1 - 1/N)))
```

점수는 0~100으로 제한합니다. 2등분 50:50은 100%, 55:45는 90%, 60:40은 80%입니다. 별점은 기존처럼 98% 이상 3개, 90% 이상 2개, 75% 이상 1개입니다. 75% 미만은 별 0개로 실패하며, 목표 조각 수 미완성으로 시간 초과한 경우에도 별 0개입니다. 별점은 반올림 전 정확도로 판정합니다.

별 아이콘과 결과 액션 SVG는 `src/icons.js`에서 관리합니다.

스테이지 선택에는 각 스테이지의 최고 정확도에 해당하는 별점을 표시합니다. 기존 기록은 그대로 읽어 별점으로 환산하며, 실패한 재도전으로 최고 별점이 내려가지 않습니다. 미도전과 별 0개 실패를 구분합니다. 성공·실패·시간 초과 모두 같은 세 가지 결과 액션을 제공합니다. 전체 결과의 완료 스테이지 수는 별 1개 이상을 받은 스테이지만 계산합니다.

래스터 근사이므로 경계·대각선·매우 좁은 조각은 몇 픽셀 정도 오차가 생길 수 있습니다. 표시 비율은 개별적으로 소수 첫째 자리까지 반올림하므로 합계가 99.9% 또는 100.1%로 보일 수 있습니다. 극소 잡음 제거 기준 아래의 조각은 별도 조각으로 세지 않습니다.

## 테스트

개발 의존성은 Playwright뿐입니다. 단위 테스트는 Node 기본 테스트 러너를 씁니다.

```sh
npm ci
npx playwright install chromium webkit
npm test                 # 순수 면적·점수·상태·저장 테스트
npm run test:e2e         # Chromium 실제 브라우저 테스트
npm run test:webkit      # Safari 계열 WebKit 테스트
npm run test:all         # 단위 + Chromium
```

설치된 Google Chrome으로 실행하려면 `PLAYWRIGHT_CHROME=1 npm run test:e2e`를 사용하세요. 테스트는 임의 포트의 별도 로컬 서버를 자동 시작·종료합니다. 화면 캡처는 `test-results/`에 생성합니다.

검증 범위: 50:50·60:40, 곡선·지그재그·빠른/느린 드래그, 내부에서 끝나는 선, 경계 부근·아주 작은 조각·자기교차, 기존 절단선 교차 및 여러 조각 동시 절단, 목표 초과 무효 처리, 되돌리기·재시작, 입력 취소·캡처 해제, 시간 초과·일시정지·백그라운드 복귀, 2.6초 연출·최고 기록·다음 스테이지·10개 스테이지 완주, 320px/390px 모바일 좌표 및 터치 스크롤 방지입니다. 실제 터치 드래그는 Chromium CDP로 검증하며, WebKit에서는 해당 CDP 전용 테스트를 제외합니다.

WebKit 자동화는 실제 iPhone Safari 기기 테스트를 대신하지 않습니다. 저사양 실제 모바일 기기의 성능과 운영체제별 제스처는 출시 전 추가 확인이 필요합니다.

## 검증 기록 및 남은 보완점

2026-10-29 기준 단위 테스트 10개, Chromium 브라우저 테스트 11개, WebKit 공통 테스트 9개를 검증합니다. WebKit에서는 CDP 전용 터치 테스트 2개를 제외합니다. 상세 기록은 [검증 보고서](docs/verification.md)를 참고하세요.

기존 동작을 유지한 범위에서, 결과 연출 도중 앱을 전환하면 2.6초 결과 타이머는 계속 진행합니다. 모달은 열릴 때 첫 버튼으로 포커스를 옮기고 배경을 `inert`로 비활성화합니다. 실기기 Safari의 주소창 변화·안전영역과 저사양 기기의 성능은 추가 확인 대상입니다.
