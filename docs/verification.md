# 안정화 검증 기록 — 2026-10-28

## 원본 분석

원본은 단일 HTML의 IIFE 내부에서 상태·입력·마스크 계산·Canvas 렌더링·UI·저장을 모두 처리했다. 게임 상태는 도전 안내 → playing → revealing → 결과 순서이며, 도움말과 탭 전환으로 일시정지했다. 10개 스테이지의 도형·분할 수·시간, 자유곡선 좌표, 마스크 해상도 560×560, 절단 폭 3.2px, 정확도 공식과 저장 키는 그대로 유지했다.

원본을 모바일 390×844 Chrome에서 실제 드래그하여 정사각형 50:50, 정확도 100%, 2.6초 후 결과 표시를 확인했다. 결과에서 남은 시간은 19.2초인데 상단 타이머는 20.0초로 돌아가는 오류를 재현했다.

## 수정 및 검증

- 빌드 없는 Vanilla JavaScript 모듈로 기존 코드를 추출했다. 게임 실행 의존성은 없고, 테스트에만 Playwright를 사용한다.
- 순수 마스크 연결 요소 계산과 Canvas 래스터화를 분리했다. 기존 4방향 탐색·극소 영역 흡수·절단선 픽셀 재배분을 유지한다. 영역 ID를 32비트로 확장하고 전체 마스크 소실 시 면적을 보존한다.
- 원래 픽셀은 조각 ID 하나에만 속하며, 조각 면적 합계는 원래 마스크 면적과 정확히 일치함을 검사했다. 조각 비율 위치도 자기 조각 안에 있는지 검사했다.
- 결과·시간 초과의 타이머를 수정했다. 드래그 완료 시 마감 시간을 즉시 검사해 마지막 주기 이후의 초과 입력도 거절한다.
- 도움말·백그라운드·재시작·시간 초과·되돌리기 때 진행 중인 입력과 캡처를 정리한다. 다른 포인터의 취소는 현재 입력에 영향을 주지 않는다.
- coalesced samples와 자유곡선 궤적을 보존하고, 미리보기 렌더링만 프레임 단위로 합쳤다.
- 2.6초 조각 비율 연출을 유지하고 결과창에 최고 기록을 추가했다. 저장 데이터 검증과 저장 실패 방어를 분리했다.

## 자동화

- `npm test`: 9개 단위 테스트. 점수 예제, 래스터 면적·조각 소유권, 내부 절단·곡선·지그재그·교차·좁은 영역, 무효·초과 분할의 원자성, 되돌리기·초기화, 저장 오류 및 스테이지 수 확장.
- `npm run test:e2e`: Chromium 9개 테스트. 데스크톱/390px/320px, 실제 드래그, 2.6초 표시 지연, 결과·최고 기록·재도전·다음 단계, 10개 전체 완주, 일시정지·시간 초과·캡처 해제·취소·탭 가시성, 실제 단일 및 다중 터치.
- `npm run test:webkit`: WebKit 7개 통과, CDP 터치 전용 2개 제외. 같은 게임/Canvas/모바일 화면 흐름을 검사한다.

모든 도형을 실제 Canvas에서 각각 목표 조각 수로 분리하고, 320px 화면에서 10개 스테이지를 UI로 완주했다. `test-results/`의 결과·비율 연출 화면과 6조각 결과창을 시각 검토했다.

WebKit은 Pointer Event 좌표를 정수로 반올림한다. 390px 보드의 중앙 좌표 466.703px가 실제 이벤트에서 466px로 전달되어 49.7:50.3, 정확도 99.4%가 나왔다. 자유곡선을 보정하지 않는 원칙을 지키며 중앙 드래그 테스트는 99% 이상, 순수 점수 테스트는 정확한 수치로 검증한다. 브라우저별 Canvas 경계 픽셀 차이도 허용하되 각 브라우저 내부에서 면적 보존은 정확히 검사한다.

별도 코드 리뷰에서 Critical/Important 문제는 발견되지 않았다. 리뷰 당시 추가 권고된 실제 다중 터치 사례는 CDP 테스트로 보강했다.

## 남은 확인

- 실제 iPhone/Safari 및 저사양 Android 기기에서 성능·OS 제스처 확인. WebKit 자동화는 실기기 검증을 대체하지 않는다.
- 원본과 동일하게 결과 연출 타이머는 탭이 숨겨져도 진행한다. 복귀 후 보이는 시간 2.6초를 보장하는 처리는 후속 보완 대상이다.
- 기존 모달의 키보드 포커스 가두기·배경 inert는 아직 적용하지 않았다.

원격 저장소 생성·push·외부 배포는 수행하지 않았다. 제공 폴더에는 Git 저장소가 없어 커밋도 생성하지 않았다.


## 별점 및 실패 처리 추가 — 2026-10-29

- 모든 스테이지에 기존 공통 기준을 적용한다: 정확도 98% 이상 별 3개, 90% 이상 2개, 75% 이상 1개, 75% 미만 0개·실패. 반올림 전 정확도로 판정하며 기준 경계값을 단위 테스트한다.
- 스테이지 선택에 최고 기록 별점을 표시하고, 미도전과 별 0개 실패를 구분한다. 기존 점수 저장 데이터를 그대로 사용하므로 별도 마이그레이션은 필요하지 않다.
- 목표 조각 수를 완성해도 정확도가 부족하면 2.6초 연출 후 실패 결과와 재도전 버튼을 먼저 보여준다. 시간 초과도 0개·실패로 기록한다. 이전 최고 별점은 유지한다.
- 전체 결과는 실패한 스테이지를 완료로 세지 않고, 모든 스테이지를 통과했을 때만 완주로 안내한다. 기존처럼 실패 후에도 다른 스테이지를 자유롭게 선택할 수 있다.
- 단위 테스트 10개, Chromium 12개, WebKit 10개(실제 터치 CDP 전용 2개 제외)로 확장했다. 기존 게임·절단 회귀 테스트와 별점 경계, 과거 기록 호환, 실패·재도전·최고 별점 유지·시간 초과·실패 포함 전체 결과를 검증한다.
- 320px 모바일의 별 0개 실패 화면과 스테이지별 별점 표시를 시각 검토했다.
