# toki-split 안정화 구현 계획

목표: 기존 index.html의 디자인, 10개 스테이지, 자유곡선 래스터 절단 및 정확도 공식을 보존하며 모듈과 회귀 테스트를 구축한다.

구조: 빌드 없는 ES modules + Vanilla JS. 런타임 의존성 없음. Node 기본 테스트와 Playwright로 검증한다. Git 저장소가 없는 제공 폴더이므로 현재 폴더에서 작업하고 원격 서비스는 사용하지 않는다.

- [x] 1. 기존 브라우저 플레이와 스코어/결과 흐름 확인. 원본은 /tmp/toki-split-baseline/index.html에 보존.
- [x] 2. src/stages.js, geometry.js, scoring.js, storage.js, game-state.js, input.js, renderer.js, main.js 및 styles.css로 기존 구현 추출. 단위 테스트로 면적 배분과 상태 복원 고정.
- [x] 3. 절단 판정의 면적 보존, 극소 영역 흡수, 무효/초과 분할 검증. 포인터 캡처·취소, 시간 종료·일시정지·재시작 상태 정리. 모듈 테스트를 먼저 작성하고 실패를 확인한 뒤 구현.
- [x] 4. 2.6초 결과 연출 유지, 최고 기록 표시 및 접근성 보완. 실제 Canvas 래스터를 사용하는 Playwright 테스트로 곡선/지그재그/교차/작은 조각/자기교차/모바일 입력 확인.
- [x] 5. 단위 및 브라우저 테스트 실행, 화면 시각 검토, README에 실행·테스트·알고리즘 한계와 검증 결과 기록.

검증 초점: 원래 도형 픽셀은 정확히 한 조각에만 배분되어야 한다. 내부 시작/끝 경로를 임의 연장하지 않는다. 목표 초과 절단은 상태를 변경하지 않는다. 다른 포인터의 취소가 진행 중인 터치를 끊지 않는다. 제한시간 종료 시점과 결과/재시작 타이머가 충돌하지 않는다.

검증 기록: docs/verification.md. 현재 폴더에 Git 저장소가 없어 커밋·worktree를 만들지 않았다.
