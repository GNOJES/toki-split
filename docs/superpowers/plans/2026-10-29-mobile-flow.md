# 모바일 화면 및 플레이 흐름 개편

사용자 요청: 홈 게임시작 → 별도 스테이지 선택 → 한 화면 게임. 플레이 중 목록 제거, 원래 시간의 1/10, 결과 아이콘 3개와 큰 별 3개, 98% 별3개 안내, 보드 눈금 제거. 기존 자유곡선/면적/점수/기록/2.6초 연출 유지. 검증 후 main push 및 기존 Vercel 프로젝트 배포.

- [x] 회귀 테스트: 홈/선택/바로 시작, 모바일·가로화면 overflow/터치, 2~5.8초 제한, 결과 아이콘·별·98%, 기존 절단과 상태 전환.
- [x] index.html에 세 화면을 분리하고 main.js에 화면 이동·취소·재시작 상태 연결. 스테이지 선택은 바로 시작.
- [x] styles.css 모바일 viewport/safe area 및 결과 UI, ui.js 별 SVG·아이콘 액션, renderer.js 눈금 제거. stage time 데이터만 1/10.
- [x] 단위·Chromium·WebKit·화면 캡처/실제 시간 검증 및 코드 리뷰. README 최신화.
배포 단계: 커밋/push 후 Vercel READY 및 공개 모바일 실제 플레이 검증. 배포 상태·커밋은 최종 작업 응답에 기록한다.

구현 선택: 기존 Vanilla JS 유지. 앱은 100dvh와 안전영역을 사용하고 게임 보드는 가용 가로·세로 중 작은 값으로 정사각형 크기를 정한다. 홈과 선택은 개별 화면이며 선택 목록만 내부 스크롤을 허용한다. 마지막 스테이지의 다음 아이콘은 전체 결과로 연결한다. 상세 판정은 도움말에 두고 결과에는 별3개 기준 한 줄만 표시한다.
